# 进化历史

> 记录这个系统从 0 到 1 的进化过程。
> 不只是记录了"做了什么"，还要记录"为什么这样做"。

## 阶段 1：系统初始化（2026-05-10）

- 基于 Blueprint v2.0 框架搭建目录结构
- 基于"周正"的完整人格画像填充内容
- 首次建立反通用化规则体系

**这个阶段做对了什么**
把人格拆成 10 个模块，把"AI 应当怎样思考"写成可加载的规则。
结构是对的。

**这个阶段埋下了什么问题**
一次性填充了 61 个文件，然后就没有然后了。
内容全部来自"根据人格画像推断"，没有一条来自真实对话的验证。
→ **这直接导致阶段 2。**

## 阶段 2：工具箱扩张，系统停滞（2026-05-12 ~ 2026-09-11）

- 05-12 至 09-11 共 6 次提交，**全部是README、工具箱集成、多平台适配**
- 自研模块 0 次改动
- `last_updated` 66/67 个文件停在 05-10

**为什么**
工具箱带来了即时可见的进展（33 个 Skill 能跑），
自研模块的进展是不可见的（规则文件变厚，但用起来没区别）。
注意力自然流向有反馈的地方。

**这个阶段暴露的真问题**
`evolution_protocol.md` 写"AI 应当自动完成沉淀"，
但没有触发机制。它靠自觉，所以它没发生。
**这不是执行问题，是设计问题——把一个机制的启动交给了没有强制力的对象。**

## 阶段 3：闭环修复（2026-10-12）

第一次对系统本身做结构审计，然后修了三处：

### 修 1：给闭环装上触发器

新增 `tools/`，两个脚本：
- `evolve.py` — 把"有没有在沉淀"变成可查数字，支持环比
- `lint_output.py` — 把 `quality_control.md` 可判定部分变成命令

`evolution_protocol.md` 从"应当自动完成"改写为四步明确操作，
并挂到 AGENTS.md / AI_START.md / rules.md 三个入口。

**为什么这样改**
一个依赖自觉的机制，失败率是 100%。实测已验证：五个月零触发。
不改成命令，它永远不会发生。

### 修 2：给"变好"一个可测量的定义

`7_ai_training/benchmark_outputs/2026-10-12_benchmark_v1.md`

三道固定题，分三层：
- A 认知层（考判断不考文笔）
- B 表达层（考风格）
- C 立场层（考敢不敢反驳）

**C 是分水岭。** 能模仿风格、无法复制立场，说明那不是人格，是文案模板。

### 修 3：给判断类目录填上第一批真实内容

- `3_behavior/decision_cases/` 首条决策轨迹（含2026-10-12 的事后回看）
- `7_ai_training/corrected_outputs/` 首条修正记录

**刻意没做的事**
- 不往 `0_system/` 加规则。已够厚。
- 不编造客户案例。真实数据只有周正知道。
- 不评价内容的对错。`thinking_protocol.md` 写了"AI 不做决策"。

### 抽象出的教训

**规则写在文件里 ≠ 规则在运行。**

判断一条规则是否真的生效，只有一个方法：去找它的失败记录。
找不到，不代表在运行，只代表还没触发。

**一个人格 OS 里如果全是观点没有决策，那它不是人格，是一个自我描述。**
观点谁都能写，决策只有做过的人才有。

## 阶段 4：待验证（2026-10-12 之后）

```bash
python tools/evolve.py
```

看"总计：N 份实际内容"。**这个数字不动，一切改进都是自我感觉。**
