# tools/ — 人格 OS 的可执行装置

> 这个目录解决一个具体问题：`0_system/evolution_protocol.md` 写的六步闭环里，
> 第 3 环（输出）和第 4 环（反馈）没有强制机制，导致闭环实际不转。
>
> 这里放两个脚本，把"AI 应当自动完成"变成"AI 执行命令"。

## 脚本

| 脚本 | 作用 | 什么时候跑 |
|------|------|-----------|
| `lint_output.py` | 检查一份文案/回答是否符合 `0_system/quality_control.md` 里**可机器判定**的部分 | AI 每次输出正文类内容后 |
| `evolve.py` | 扫描记忆与训练目录，报告哪些还是空模板；维护进化状态文件 | 每次会话结束时 |

## 设计原则

1. **只检查可机器判定的规则。** 风格、洞察、锐度这些人工判断不写进脚本——
   脚本判不了的东西硬判，只会训练出"为了过检而写作文"。
2. **报告而不阻断。** 脚本不以非零退出码阻断工作流，只输出报告。是否修改由人决定。
3. **状态写在仓库里。** `9_meta/evolution_state.json` 让"有没有在进化"变成可查的数字，
   不再依赖记忆和感觉。

## 用法

```bash
# 检查一份待输出内容
python tools/lint_output.py 待检查.md

# 扫描闭环健康度
python tools/evolve.py
```

两个脚本都是纯标准库 Python 3，无第三方依赖。
