# 进化协议

## 每次交互的进化循环

```
输入 → 分析 → 输出 → 反馈 → 提取认知 → 更新系统
```

**关键认知（2026-10-12 补）**：
这条循环写了五个月，但第 3-6 环的产出全是 0。
原因不是"没坚持"，是**第 6 环没有任何触发机制**。
下面这版把"应当"改成"执行"，并给执行装上启动器和拦截。

## 启动器：一次性安装

```bash
python tools/launcher.py install
```

装完之后，三件事自动发生，不依赖 AI 记不记得：

| 机制 | 效果 |
|------|------|
| pre-commit hook | 改了 `0_system/` 或 `1_identity/` 却没记变更日志 → **拦住 commit** |
| pre-push hook | 每次 push 前自动打印闭环体检 |
| 定时采集（每 2 小时） | 新会话自动变成待审草稿到 `8_contexts/inbox/` |

**新客户端接入时先探测能不能采到**：`python tools/capture.py`
实测当前结论：Claude Code ✅ / Codex ⚠️ / WorkBuddy ❌（正文不在本地库）。

详见 `tools/LAUNCHER_启动器说明.md`。

## 每次会话结束时，必须执行的四步

### 第 1 步：跑机检（如果这次输出了正文类内容）

```bash
python tools/lint_output.py <本次输出文件>
```

脚本检查 `0_system/quality_control.md` 里可机器判定的部分：
禁用空词、引导互动话术、句长、段长、人设回收。

**脚本判不了风格和洞察**——那部分仍然只能人来看。

### 第 2 步：跑闭环扫描

```bash
python tools/evolve.py
```

看"总计：N 份实际内容"。这个数字是系统有没有在进化的**唯一客观指标**。

### 第 3 步：清理待审草稿

读 `8_contexts/inbox/` 里的草稿，答开头三问：

1. 有没有**真实的决策**（做了什么选择、被否了什么、结果如何）？
2. 有没有 **AI 说错了、被纠正**的地方？
3. 有没有**当时以为对、后来被验证是错的**判断？

有 → 提炼进对应目录。**三条都是"否" → 直接删掉草稿，不用留。**

### 第 4 步：如果改了系统规则，写日志

```
YYYY-MM-DD | 文件 | 变更类型 | 变更说明
```

追加到 `9_meta/system_changes.md`，并在 `9_meta/update_logs.md` 记一笔。

**这一步有 pre-commit hook 拦着。** 改了核心规则不记日志，commit 会失败。
确实需要跳过时：`git commit --no-verify`

## 沉淀的门槛

**宁可漏记，不要编造。**

一条假的修正记录会污染整个系统，比空着更糟。
判断标准：这条记录里有没有**只有做过才知道的东西**？
没有 → 是废话，别写。

## 自动化到哪一步为止

| 环节 | 能否自动化 | 现状 |
|------|-----------|------|
| 捞对话 | ✅ 能 | `capture.py` 读客户端本地日志，每 2 小时跑 |
| 拦没记日志的提交 | ✅ 能 | pre-commit hook |
| push 前体检 | ✅ 能 | pre-push hook |
| 生成待审草稿 | ✅ 能 | `capture.py --draft` |
| **判断哪条值得沉淀** | ❌ **故意不做** | 自动判断会把垃圾和金子一起捡 |
| **提供真实客户决策** | ❌ **AI 代替不了** | 只有周正知道，编的会污染系统 |

**"自动收录对话"做不到全自动。** AI 客户端不会把对话推给仓库，
`capture.py` 的做法是读它们写在本地硬盘上的日志。
客户端不写本地日志的（实测：WorkBuddy 正文不在本地库），就采不到。

这不是脚本的问题，是客户端不给你数据。

## 什么不写进系统

- 闲聊、寒暄
- 泛泛鼓励
- 重复已有的认知
- AI 生成的、未经周正确认的判断

## 禁止的进化方式

- **不增加规则数量来假装在进化。** `0_system/` 已够厚，加规则前先问：
  能不能用删除代替新增？
- **不改核心规则。** 0_system 级的修改需要至少 3 条真实案例支撑，不能凭一次感觉。
- **不为指标写内容。** 如果"实际内容数量"是靠编出来的，这个数字毫无意义。

## 长期进化的判定标准

每季度看一次 `9_meta/evolution_state.json`：

| 指标 | 健康 | 危险 |
|------|------|------|
| 实际内容份数 | 持续上涨 | 长期不变 |
| 基准测试总分 | 趋势向上 | 原地踏步 |
| 规则字符数 | 稳定或下降 | 持续上涨（说明在加废话） |
| 决策轨迹 / 总认知数 | > 1:3 | < 1:10（说明只有观点没有决策） |

**最后一行最关键。** 观点谁都能写，决策只有做过的人才有。
如果一个人格 OS 里全是观点没有决策，那它不是人格，是一个自我描述。
